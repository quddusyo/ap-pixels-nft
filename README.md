# AP Pixels NFT

**AP Pixels** is a web-based NFT landing page and minting app for a digital art collection. Designed with a responsive UI and React components, this project showcases how to integrate Web3 concepts with a frontend interface for NFT drops.

> This version is under the `version-jan-10` branch and is intended for project iteration and Web3 minting functionality enhancements.

---

## Features

- Clean and responsive NFT landing page
- Wallet connect integration (Metamask-ready)
- React-based minting interface
- Optimized component structure for scalability
- Frontend optimized for user engagement

---

## Tech Stack

- **Frontend:** React.js, HTML5, CSS3
- **Web3:** Web3.js / Ethers.js
- **Wallets:** Metamask / WalletConnect
- **Design:** Responsive layout using CSS modules or inline styles
